# ReUseHub – Give Resources a Second Life

A modern, responsive community resource-sharing frontend built with **React, Vite, Tailwind CSS, React Router, and Lucide React**.

## Features
- **Public Marketplace:** Hero landing page, category filters (*Books, Furniture, Electronics, Stationery, Others*), recently added resources, impact counters, and resource detail pages.
- **Authentication & Roles:** Login and Registration with Donor/Receiver role selection, form validation, and 1-click demo portal access.
- **Receiver Dashboard:** Browse & search resources, submit quantity + purpose claims, track claim status (`Pending`, `Approved`, `Rejected`, `Completed`), view pickup schedules with generated **QR pickup passes**, notifications, and profile settings.
- **Donor Dashboard:** Create listings with photo uploads, edit/pause/close/delete listings, review incoming claims, approve with QR pass issuance, verify handoffs, and view environmental impact analytics.
- **Admin Dashboard:** Platform KPIs, user enable/disable management, listing moderation, organization verification queue, analytics & reports, and configurable platform settings.
